    Come sono misurate le distanze

    Tutte le distanze di questo sito sono in linea d'aria dal centro paese: l'incrocio Via Turati / Via Francesca / Via Garibaldi / Via Sette Frati, a 45.18019 N, 10.67714 E. Non sono distanze stradali e non vanno usate come tali.

    Il dataset

    Tutto ciò che sta nelle tabelle di questo sito viene da un solo file JSON strutturato, allegato qui sotto.

    ChiaveContenuto
    metalocalità, comune, provincia, CAP, coordinate del centro, fonte, data di estrazione
    poipunti d'interesse con id OSM, nome, categoria, tipo, coordinate, distanza dal centro, indirizzo, telefono, web, orari e tag completi
    stradeassi viari denominati con tipo, lunghezza, superficie, limite, senso unico, illuminazione, ref e numero di segmenti
    civici_mappatinumeri civici presenti in OSM, raggruppati per via
    elementi_stradalidossi, attraversamenti, dare-precedenza, stop, autovelox, barriere
    incroci106 nodi fra vie denominate, con coordinate e distanza
    corsi_acquafiumi, canali, scoli e fossi con tipo, nome e lunghezza mappata

    Rigenerare i geodati

    Estratto completo dell'area

    curl "https://api.openstreetmap.org/api/0.6/map?bbox=10.6560,45.1660,10.6980,45.1940" -o rivalta.osm

    Interrogazioni mirate via Overpass API

    Conviene usare il mirror https://overpass.private.coffee/api/interpreter: quello ufficiale è spesso saturo.
