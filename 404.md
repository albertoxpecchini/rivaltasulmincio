# 404.md

## Scopo

Definisci pagina errore **404 — Pagina non trovata** per **Rivalta sul Mincio — il paese, in ogni suo dato**.

La pagina deve mantenere identità visiva del progetto.

Non deve sembrare errore tecnico.

## Obiettivo

Quando URL non esiste:

* informa chiaramente;
* spiega problema;
* permette ritorno rapido;
* mantiene navigazione;
* conserva stile atlante digitale.

## Contenuto

Titolo principale:

```text
404
```

Titolo secondario:

```text
Pagina non trovata
```

Testo:

```text
Questa pagina non esiste oppure non è più disponibile.
```

Azioni principali:

```text
Torna alla home
Esplora la mappa
```

## Struttura

Ordine:

```text
404
Pagina non trovata
Descrizione breve
Azioni
Eventuale ricerca
Eventuale mappa
```

Non aggiungere paragrafi lunghi.

## Identità

Pagina deve usare:

* colori definiti in `COLORS.md`;
* tipografia definita in `TYPOGRAPHY.md`;
* spacing definito in `SPACING.md`;
* icone definite in `ICONS.md`;
* logo definito in `LOGO.md`.

Non creare stile separato.

## Visual

Possibile elemento centrale:

* coordinate;
* griglia cartografica;
* marker;
* piccola rappresentazione mappa;
* linea territoriale.

Elemento deve suggerire "posizione non trovata".

Non usare immagini stock.

Non usare illustrazioni generiche da template.

## Animazione

Animazione opzionale.

Possibili effetti:

* marker leggermente spostato;
* coordinate che cambiano;
* linea cartografica che appare.

Animazione deve essere breve e non necessaria alla comprensione.

Rispetta:

```css
@media (prefers-reduced-motion: reduce) {
  /* disable non-essential animation */
}
```

## Navigazione

Header deve restare disponibile.

Logo deve portare a `/`.

Navigazione principale deve restare funzionante.

Footer deve restare disponibile.

## Ricerca

Può essere presente una ricerca globale.

Placeholder:

```text
Cerca Rivalta sul Mincio
```

Permetti ricerca di:

* luoghi;
* attività;
* servizi;
* strade;
* eventi;
* dati.

## Mappa

Pulsante:

```text
Esplora la mappa
```

porta a:

```text
/mappa
```

Non caricare una mappa pesante solo per decorare pagina 404.

## Responsive

Mobile:

```text
404
Pagina non trovata
Descrizione
Azioni verticali
```

Desktop:

```text
contenuto centrato
```

Mantieni spazio sufficiente senza creare enorme vuoto.

## Accessibilità

Usa:

```html
<main>
```

Titolo pagina deve essere `h1`.

Pulsanti e link devono avere nome chiaro.

Focus visibile.

Navigazione tastiera completa.

Non comunicare errore soltanto tramite colore.

## SEO

Imposta:

```text
HTTP status: 404
```

Non restituire `200 OK` per pagina inesistente.

Pagina 404 non deve essere indicizzata.

Usa:

```html
<meta name="robots" content="noindex">
```

quando compatibile con architettura del progetto.

## URL

Qualsiasi percorso inesistente deve mostrare pagina 404 coerente.

Esempi:

```text
/rivalta-xyz
/mappa/luogo-inesistente
/attivita/non-esistente
```

## Query

Parametro inutili o URL malformati non devono rompere pagina.

Esempio:

```text
/mappa?place=inesistente
```

deve mostrare stato appropriato senza errore JavaScript non gestito.

## Errori API

Errore API non equivale necessariamente a 404.

Distinguere:

```text
404 = risorsa non esistente
500 = errore server
503 = servizio temporaneamente non disponibile
```

Non mostrare pagina 404 quando API semplicemente non risponde.

## Logging

Registra 404 utili lato infrastruttura quando sistema lo permette.

Usa dati aggregati.

Non raccogliere dati personali inutili.

Monitora URL rotte frequenti.

## Link interni

Pagina deve offrire almeno un percorso utile verso contenuto reale.

Priorità:

```text
Home
Mappa
Ricerca
```

## Nessun redirect automatico

Non reindirizzare automaticamente ogni 404 alla home.

Utente deve vedere chiaramente che URL non esiste.

Redirect automatico ammesso solo quando esiste corrispondenza certa e documentata.

## Errori comuni

Evita:

```text
Something went wrong
Oops!
404 lol
Page missing
```

Usa italiano coerente con progetto.

## Fallback

Pagina deve funzionare anche quando:

* JavaScript non carica;
* API non rispondono;
* immagini falliscono;
* font personalizzati non sono disponibili.

Contenuto principale deve restare leggibile.

## Performance

404 deve essere leggera.

Non caricare:

* dataset completi;
* mappe pesanti;
* immagini grandi;
* script inutili.

## Test

Verifica:

```text
/404
/percorso-inesistente
/mappa/inesistente
/attivita/inesistente
/luoghi/inesistente
```

Controlla:

* status HTTP 404;
* layout;
* responsive;
* link;
* accessibilità;
* console;
* SEO;
* performance.

## Regola finale

**Errore chiaro. Recupero immediato. Stile coerente. Nessun errore tecnico esposto.**

Anche una pagina inesistente deve sembrare parte dell'atlante di Rivalta.
